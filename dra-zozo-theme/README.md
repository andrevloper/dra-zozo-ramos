# Dra Manuela Theme

Tema WordPress premium para o site da Dra. Manuela - Nutrição Animal.

## Instalação

1. Faça o upload da pasta `dra-manuela-theme` para `wp-content/themes/`.
2. Ative o tema no painel WordPress.
3. Instale e ative o plugin Elementor para edição visual das páginas.
4. Crie as páginas necessárias: Home, Sobre, Serviços, E-books, Contato.
5. Configure o menu principal.
6. Para formulários, instale Contact Form 7 e adicione o shortcode no index.php.

## Estrutura

- `index.php`: Página inicial com seções fixas.
- `page.php`: Template para páginas padrão.
- `header.php`: Cabeçalho com navegação.
- `footer.php`: Rodapé.
- `functions.php`: Scripts, estilos e configurações.
- `style.css`: Estilos CSS.
- `js/main.js`: JavaScript para interatividade.

## Personalização

Use Elementor para editar páginas individuais. O tema é compatível com Elementor.
